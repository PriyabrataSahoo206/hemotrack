# HemoTrack — Moving Lifelines. Saving Lives.

HemoTrack is a healthcare coordination and logistics platform designed to connect hospitals, blood banks, and authorized delivery partners to streamline time-sensitive blood fulfillment.

🌐 **Official Website:** https://hemotrackmedico.netlify.app/

## About HemoTrack

HemoTrack aims to improve coordination and visibility across the blood fulfillment workflow, from submitting a blood requirement and confirming availability to coordinating transportation and tracking delivery status.

The platform focuses on reducing fragmented communication and improving operational transparency among participating healthcare organizations and authorized logistics partners.

## Key Objectives

- **Blood Requirement Coordination:** Organize and track blood requests.
- **Availability Visibility:** Support coordination around verified blood availability.
- **Fulfillment Tracking:** Track request progress and delivery status.
- **Stakeholder Connectivity:** Connect hospitals, blood banks, and authorized delivery partners.
- **Workflow Transparency:** Maintain clear status updates throughout the fulfillment process.

> Clinical verification, compatibility decisions, and blood release remain the responsibility of authorized healthcare professionals and institutions.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- A Gemini API key, if required by the current application implementation

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env.local` file in the root directory if the application requires Gemini API access.

```env
GEMINI_API_KEY=your_gemini_api_key
```

**Security:** Never commit API keys, passwords, or other secrets to your repository. Ensure `.env.local` is included in `.gitignore`.

### 4. Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
